# Symbol Art Studio 1.1

PSO2 / PSO2 NGS Symbol Art 的离线多语言预览、图层编辑工具。

## 启动

双击 `SymbolArtStudio.html`，用桌面版 Chrome、Edge 或 Firefox 打开。
无需安装 Python、Node.js、服务器或联网。素材、解码器和你的原始 SAR 样本均已内置。
如果在聊天附件预览中不执行脚本，请先下载到电脑，再在浏览器打开。

## 语言切换（v1.1）

右上角“语言 / Language / 言語”可切换 **简体中文、English、日本語**。默认简体中文，选择会保存到当前浏览器，下次打开自动恢复（浏览器允许本地存储时）。切换即时生效，不修改作品名、自定义图层名、图层数据、选中状态或撤销记录。界面、提示、确认弹窗、错误消息及内置使用说明均已翻译；GPL 许可全文保留英文原文。

**English:** Use the top-right Language menu to select English, 日本語 or 简体中文. Your choice is remembered locally. Switching does not change artwork data or undo history.

**日本語：** 右上の「言語」メニューで日本語・English・简体中文を切り替えられます。選択はブラウザーに保存され、作品データや操作履歴は変更されません。

## 已实现

- 导入压缩 SAR (`sar 84`) 和未压缩 SAR (`sar 04`)。
- Blowfish 解码 / 编码、PRS 解压；内置 376 个符号 PNG 素材。
- 游戏裁切预览、完整 0–255 工作区、透明 / 白色 / 深色背景。
- 图层列表与画布点击选中；拖动移动、拖动四角、精确坐标输入。
- 颜色（游戏 6 位色阶）、不透明度（8 档）、显示 / 隐藏。
- 旋转、缩放、水平 / 垂直翻转；新建、复制、删除、调整层序。
- 撤销 / 重做（80 步），本地自动草稿，拖放文件。
- 改名、Symbol Art / 联盟旗帜画幅切换、音效编号保留 / 编辑。
- 导出 `.sar`、透明 PNG（普通 1536×768，旗帜 512×512）、JSON 工程。
- 保留作者 ID、四个原始顶点、原始色阶索引和完整第二属性字。

工具打开后默认加载 `Yume's_XIERRA_4.sar`：114 层、27 种符号、原始文件 1288 字节。

## 操作

1. 点“打开 SAR / 工程”，或拖入文件。
2. 左侧选择图层，右侧修改属性。画布拖动已选图层移动；四角方框可分别变形。
3. 双击图层行可以重命名（此名称仅保存在 JSON 工程里）。
4. 图层列表越靠上，叠放位置越靠前。“上移 / 下移”调整遮挡顺序。
5. 选中层被其他图层遮挡时，可以勾选“仅选中层”。完整工作区的虚线框表示游戏范围。
6. 修改后导出 SAR。PNG 总是导出游戏裁切范围内的全部可见图层，忽略“仅选中层”，不带控制点或网格背景。

快捷键：Ctrl/Cmd+Z 撤销；Ctrl/Cmd+Shift+Z 或 Ctrl+Y 重做；Ctrl/Cmd+D 复制；Delete 删除；Ctrl/Cmd+S 导出 SAR；方向键 1 单位移动，Shift+方向键 10 单位。

坐标必须是 0–255 的整数。移动遇到边界会停下，越界旋转或缩放会拒绝并回退。四角自由变形保留在文件中；极端自交四边形可能在游戏中产生不同效果。

## 文件与兼容性

- 导出使用未压缩 `04` SAR。样本未修改时导出 1866 字节，原文件的压缩体积是 1288 字节。解码后的 payload 完全相同，体积差异不是内容丢失。
- `.sar` 最多 225 层；宽画幅编码 192/193 × 128、旗帜 64 × 64。实际 PNG 显示输出为 2:1 或 1:1。
- 预览中心为 SAR 坐标 (127,127)，可见顶点跨度 191×95（旗帜 31×31），沿用参考编辑器的裁切规则。
- 名称输入最多 20 个 UTF-16 代码单元，导入时保留现有名称。扩展 JSON 可携带不超过 64 个代码单元的名称；游戏可能对较长名称自行截断。
- 缺少素材时会显示具体符号 ID；该图层预览空缺，但导出保留其数据，不会悄悄替换成其他形状。内置素材并非所有历年 / 当前游戏新增素材的保证。
- 音效只保留 / 编辑编号，不播放预听；扩展属性原样保留，但未明确用途的字段不参与预览。
- 不支持 `.saml`、PNG/JPG 自动转 SAR、分组、多选、整目录批量预览。
- JSON 工程是本工具专用格式，不是游戏文件。浏览器草稿受本地存储策略影响；请下载文件作为正式保存。
- 已进行数据往返与浏览器操作验证；当前环境没有 PSO2 客户端，不能代替游戏内导入 / 渲染验证。

## 开发与构建

完整源码随包提供。修改 `app.js`、`codec.js`、`renderer.js`、`style.css` 和 `index.template.html` 后，运行：

```sh
python build.py
```

只需 Python 3 标准库。`assets.js` 内嵌 PNG 数据、默认样本及 GPL 许可。`vendor/BlowfishCrypto.js` 是保留原许可声明的第三方实现。

翻译目录：`locales.json`（以简体中文为键，对应英语和日语）；`i18n.js` 负责界面更新和语言记忆。修改翻译后重新运行 `python build.py`。语言回归测试见 `tests/i18n.test.cjs`。

算法测试（Node.js 18+）：

```sh
node tests/codec.test.cjs
```

浏览器测试：安装 Playwright 并准备 Chromium 后运行 `node tests/browser.test.cjs`。可用环境变量 `CHROMIUM_PATH` 指定浏览器。测试使用本地 file URL，不启动或访问服务器。
