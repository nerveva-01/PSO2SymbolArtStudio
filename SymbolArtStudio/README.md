# Symbol Art Studio 1.3

[简体中文](README.md) | [English](README.en.md) | [日本語](README.ja.md)

## 新增功能

- **语言自动适配**：默认跟随浏览器首选语言（通常来自系统设置）。中文 `zh` 及其地区 / 脚本变体显示简体中文，日语 `ja` 显示日语，其余语言一律显示英语。只按首选语言判断，不因次选语言含中文或日语而切换。可在语言菜单手动选择并记忆；选择「自动（系统）」恢复自动适配。浏览器未提供语言时默认英语。
- **作品名与文件名**：图库卡片同时显示 SAR 内部作品名和实际 SAR 文件名；悬停可查看完整作品名与相对路径。作品名为空时显示「未命名作品」，读取失败仍保留文件名。

- **随机加载示例**：从当前 sample 文件夹读取 SAR，多个有效文件时避免连续加载同一个；遇到无法解析的文件会跳过。
- **浏览示例**：同时显示多张 SAR 缩略图，支持文件名 / 相对路径搜索、24 张一页、选择和翻页。
- **双击缩略图**（或 Enter /「打开所选文件」）：把作品载入原编辑器，可查看和修改所有图层。存在未导出修改时先确认。
- 普通画幅与联盟旗帜均按各自游戏裁切范围预览；不显示编辑控制点。缺失素材、坏文件和空目录有提示。
- 预览不会修改编辑中的作品；所有图片在本机生成，文件不会上传。

## 推荐使用：自动读取 sample

1. 解压整个压缩包。
2. 把自己的 `.sar` 文件放进 `sample` 文件夹，可包含子文件夹和 `.SAR` 大写扩展名。
3. 已安装 Python 3.8 或以上：Windows 双击 `start.bat`；其他系统运行 `python3 serve.py`。
4. 浏览器打开后点击「随机加载示例」或「浏览示例」。添加 / 删除文件后点击图库中的「刷新列表」。

服务只监听 `127.0.0.1`，不对外发布。端口占用时运行 `python serve.py --port 8766`。关闭终端即可停止服务。

包内 `sample/original.sar` 是从原 HTML 内嵌示例无损提取的文件，只有这一份真实示例。添加更多 SAR 后才会出现更多缩略图和随机切换。

## 无需安装：直接打开 HTML

双击 `SymbolArtStudio-v1.html`，点击「浏览示例」→「选择 sample 文件夹」，选择你的文件夹。也可先点「随机加载示例」，再选择文件夹，自动随机打开一个文件。

由于浏览器本地文件权限限制，HTML 不能自行扫描相邻硬盘目录；直接打开时需要手动选择文件夹，刷新页面后需重新选择。选择文件夹只用于浏览器本地读取，不上传。新增 / 删除文件后点「刷新列表」重新选择目录。

编辑后沿用「导出 SAR」或「保存工程」下载结果；不会自动覆盖磁盘上的原始 sample 文件。若要更新图库中的原件，把导出的文件放回 sample，再刷新列表。

## 静态服务器

可用普通静态服务器托管完整文件夹。`sample/manifest.json` 包含相对 sample 的文件路径列表。添加文件后运行 `python serve.py --manifest` 重建清单；自带启动器每次自动生成最新列表，无需手工生成。没有清单时可尝试读取服务器目录索引（此回退只枚举当前层）。

## 源码

- `src/editor.js`：编辑器和图库接入。
- `src/samples.js`：文件夹发现 / 选择、随机抽取、搜索、分页、缩略图渲染与缓存。
- `src/samples.css`：图库样式。
- `src/index.template.html`、`src/styles.css`：页面与原编辑器样式。
- `src/sar.js`、`src/blowfish.js`：SAR 编解码及密码算法实现。
- `src/renderer.js`：原生 WebGL 渲染器。
- `src/i18n.js`：原界面多语言；图库翻译在 samples.js 中。
- `src/assets.js`：原有内嵌符号素材和许可文本。
- `build.py`：把上述源文件嵌入为完整单文件 HTML，无 npm / 外部依赖。
- `serve.py`、`start.bat`：本地启动和 sample 自动扫描。

修改 src 后运行 `python build.py`。生成的 HTML 包含全部可读源码，可独立打开。运行环境需要支持 WebGL 的现代桌面浏览器；建议 Chrome / Edge / Firefox。选择文件夹功能依赖浏览器对目录选择的支持。

图库每页最多 24 张，最多缓存 120 张缩略图与 64 个解析后的作品，复用一个预览 WebGL 上下文，避免大量示例创建过多上下文。打开作品前深拷贝数据，编辑不会污染示例缓存。
