# Symbol Art Studio 1.3

[简体中文](README.md) | [English](README.en.md) | [日本語](README.ja.md)

## 機能

- **言語の自動選択**：初期状態ではブラウザーの第一優先言語に従います。通常、この設定は OS の言語設定を引き継ぎます。中国語（`zh` および地域・文字体系の指定を含む）は簡体字中国語、日本語（`ja`）は日本語、それ以外はすべて英語で表示します。第二優先以降に中国語や日本語があっても、第一優先が別の言語なら英語になります。言語情報が取得できない場合も英語です。手動で選んだ言語は保存されます。自動選択に戻すには **「自動（システム）」** を選択してください。
- **作品名とファイル名**：各プレビューカードに、SAR 内部の作品名と実際の SAR ファイル名を別々に表示します。マウスを重ねると完全な作品名と相対パスを確認できます。作品名が空の場合は「無題の作品」と表示し、読み込めないファイルでもファイル名は残ります。
- **ランダム読込**：現在の sample フォルダーから SAR を選んで開きます。有効なファイルが複数ある場合は連続して同じファイルを開かず、読み込めないファイルはスキップします。
- **サンプル一覧**：複数のサムネイルを同時に表示します。ファイル名・相対パスで検索でき、1 ページに最大 24 件を表示します。
- **ダブルクリックで編集**：サムネイルをダブルクリックするか、Enter キーまたは「選択して開く」を使うと、元のエディターで表示・編集できます。未保存の変更がある場合は、作品を置き換える前に確認します。
- 通常サイズの作品とチームフラッグは、それぞれのゲーム表示範囲でプレビューします。編集用ハンドルは表示しません。不足素材、無効なファイル、空のフォルダーはメッセージで案内します。
- プレビュー操作で編集中の作品が変わることはありません。処理はローカルで行い、ファイルをアップロードしません。

## 推奨：sample フォルダーを自動読込

1. ZIP 全体を展開します。
2. `.sar` ファイルを `sample` フォルダーに入れます。サブフォルダーと大文字の `.SAR` 拡張子にも対応します。
3. Python 3.8 以上がインストールされている環境で、Windows では `start.bat` をダブルクリックします。その他の OS では `python3 serve.py` を実行します。
4. ブラウザーで「サンプルをランダム読込」または「サンプル一覧」をクリックします。ファイルを追加・削除した後は「一覧を更新」をクリックします。

サーバーは `127.0.0.1` のみで待ち受け、インターネットには公開しません。ポートが使用中の場合は `python serve.py --port 8766` を実行してください。ターミナルを閉じるか Ctrl+C で停止できます。

同梱の `sample/original.sar` は、元の HTML に埋め込まれていたサンプルをそのまま抽出したものです。同梱作品はこの 1 件のみです。ほかの SAR を追加すると、複数のプレビューとランダム切り替えを利用できます。

## インストール不要：HTML を直接開く

`SymbolArtStudio-v1.html` をダブルクリックし、「サンプル一覧」→「sample フォルダーを選択」からフォルダーを選んでください。先に「サンプルをランダム読込」をクリックしてからフォルダーを選ぶと、その中からランダムに開きます。

ブラウザーのセキュリティ制限により、ローカル HTML は隣接するディスク上のフォルダーを自動走査できません。この方法では手動でフォルダーを選択し、ページを再読み込みした後も選び直してください。選択したファイルはローカルで読み込むだけで、アップロードされません。ファイルを追加・削除した場合は「一覧を更新」からフォルダーを選び直してください。

編集後は「SAR 書き出し」または「プロジェクト保存」で結果をダウンロードします。sample 内の元ファイルは自動で上書きしません。一覧内の元ファイルを更新するには、書き出したファイルを sample に戻してから一覧を更新してください。

## 静的サーバーでの利用

フォルダー全体を通常の静的 Web サーバーで配信することもできます。`sample/manifest.json` には sample からの相対ファイルパスを記載します。ファイル追加後は `python serve.py --manifest` で一覧を再生成してください。同梱ランチャーは毎回最新の一覧を動的に生成するため、この操作は不要です。manifest がない場合はサーバーのディレクトリ一覧を試しますが、この代替方式で取得するのは現在の階層だけです。

## ソースコード

- `src/editor.js`：エディターとサンプル一覧の連携。
- `src/samples.js`：フォルダー検出・選択、ランダム読込、検索、ページ切り替え、サムネイル生成・キャッシュ、一覧画面の翻訳。
- `src/samples.css`：一覧画面のスタイル。
- `src/index.template.html`、`src/styles.css`：ページ構造と元のエディターのスタイル。
- `src/sar.js`、`src/blowfish.js`：SAR のデコード・エンコードと暗号処理。
- `src/renderer.js`：ネイティブ WebGL レンダラー。
- `src/i18n.js`：元の UI の翻訳と自動言語選択。
- `src/assets.js`：埋め込みシンボル素材とライセンス本文。
- `build.py`：ソースを埋め込んだ単一 HTML を生成します。npm や外部依存パッケージは不要です。
- `serve.py`、`start.bat`：ローカル起動と sample 一覧の自動生成。

src を編集したら `python build.py` を実行してください。生成した HTML には読みやすいソースコードが含まれ、単独でも開けます。WebGL に対応した最新のデスクトップブラウザーを使用してください。フォルダー選択にはブラウザーのディレクトリ選択機能が必要です。

一覧は 1 ページ最大 24 件で、最大 120 枚のサムネイルと 64 件の解析済み作品をキャッシュします。プレビュー用 WebGL コンテキストは 1 つを再利用します。編集前に作品データをディープコピーするため、編集内容がサンプルのキャッシュに影響することはありません。
